Termos de Uso

O sistema AAPM é destinado ao gerenciamento de produtos, vendas, clientes e armários da instituição.

Uso responsável

Utilize sua conta apenas para atividades autorizadas e mantenha seus dados de acesso em segurança.

Atualizações

Estes termos podem ser atualizados para acompanhar melhorias no sistema e nas rotinas administrativas.

{% elif pagina == 'privacidade' %}

Política de Privacidade

Os dados cadastrados no sistema são usados exclusivamente para as atividades administrativas da AAPM.

Dados tratados

Podem ser armazenados dados de produtos, vendas, clientes e usuários necessários para operar o sistema.

Proteção dos dados

O acesso às informações é restrito a usuários autorizados, de acordo com seu perfil de acesso.
